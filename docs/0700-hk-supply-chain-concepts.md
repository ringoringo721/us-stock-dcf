# 0700.HK（騰訊）供應鏈節點怎麼選（外部夥伴版）

對應種子：`cache/supply-chain/0700.HK.json`（PR [#139](https://github.com/ringoringo721/us-stock-dcf/pull/139)）。  
**模型：`china-platform-builder-v1`（中國平台建造／運營價值鏈）**

鏡頭：騰訊**自研**遊戲、微信、微信支付——這些是產品／平台本身，**不進供應鏈階段**。  
供應鏈只列**外部投入與夥伴**：基建、到達、支付軌道、廣告主／商戶。  
營收錨（FY2025）：VAS ~49%、FinTech ~31%、Marketing ~19%——用來理解現金流，不是把遊戲工作室塞進蜘蛛圖。

---

## 1. 主力市場

現金流與產品重心在**中國**。節點以**港股／中國相關上市**為主；雙重上市優先 `.HK`。  
對手弧維持中國產品真對手（網易／快手／阿里／百度／B 站），**不變**。

---

## 2. 為何拿掉遊戲／IP 階段

| 做法 | 原因 |
|------|------|
| **刪除 `game-ip`** | 騰訊遊戲以自研／自發為主；IP／工作室不是「外部供應鏈投入」 |
| **刪除 `social-graph`** | 微信圖譜本身是自建平台；不把自研產品拆成上游階段 |
| **保留／恢復 `distribution`** | 電信與終端是**外部到達夥伴**（流量怎麼碰到用戶） |
| **保留 `infra`／`payments`／`advertisers`** | 分別是外部基建、支付清算軌道、營銷變現下游 |

遊戲競爭關係仍由**對手弧**表達（如 9999 網易），不塞進階段玩家。
